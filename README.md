🚀 Hướng Dẫn Cài Đặt & Chạy Dự Án
> ⚠️ **Lưu ý quan trọng:** Dự án được chia làm 2 phần chạy độc lập. Vui lòng mở **2 cửa sổ Terminal** (Command Prompt / Git Bash) để khởi động song song.
1️⃣ Khởi động Backend (Máy chủ API)
Mở Terminal 1, di chuyển vào thư mục `backend` và chạy các lệnh:
```bash
cd backend
npm install
node server.js
```
Địa chỉ: `http://localhost:5000`
📌 Lưu ý: Hệ thống sẽ tự động khởi tạo thư mục `data/` chứa các file JSON. Vui lòng không xóa thư mục này khi ứng dụng đang chạy.
2️⃣ Khởi động Frontend (Giao diện)
Mở Terminal 2, di chuyển vào thư mục `frontend` và chạy các lệnh:
```bash
cd frontend
npm install
npm run dev
```
Địa chỉ: `http://localhost:5173` (hoặc cổng khác được hiển thị trên terminal)
🌐 Trình duyệt: Khuyến nghị mở bằng Google Chrome để có trải nghiệm tốt nhất.
